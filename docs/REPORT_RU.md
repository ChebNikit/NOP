# NOP BuildKit R12.2 — сокращение установочного комплекта

R12.2 уменьшает файлы внешних конвертеров внутри `dist/NOP`, которые Inno включает в `NOP_Setup.exe`. Исходный `NOP_1.0.py`, его панели, перечень 140 форматов в 11 категориях, mpv, FFmpeg и код преобразования файлов не изменены. Сохраняются исправление ранней проверки Inno из R12.1, короткая рабочая папка и импорт соседних кэшей.

## Измеренный состав файлов

Настоящие закреплённые Windows-пакеты извлечены как данные на Linux, сокращены и восстановлены побайтно. Это измерение распакованных файлов без генерируемых манифестов; **это не размер сжатого NOP_Setup.exe и не выполненная конвертация на Windows**.

| Движок | До, МиБ | После, МиБ | Убрано, МиБ |
|---|---:|---:|---:|
| libreoffice | 1498.9 | 653.2 | 845.8 |
| blender | 926.5 | 699.2 | 227.2 |
| inkscape | 636.2 | 453.5 | 182.7 |
| calibre | 558.8 | 499.2 | 59.6 |

Всего убирается **1,379,183,242 байт, примерно 1.284 ГиБ**, или 36.3% исходных файлов четырёх движков. Окончательная экономия конкретной Windows-сборки может быть меньше: при регрессии сборщик возвращает полный соответствующий движок. Размер полученного EXE будет записан в `release/CONVERTER_COMPACTION_REPORT.json` как `installer_bytes`. Полный прежний установщик здесь не собран, поэтому процент уменьшения EXE не заявляется.

## Что отобрано

- LibreOffice: удаляются переводы интерфейса движка кроме английского и русского, дополнительные темы значков редактора, словари проверки орфографии и синонимов. Их записи удаляются из `dictionaries.xcu` с сохранением пространств имён и типов XML. **Все словари переносов строк и их регистрации, все шрифты, фильтры Writer/Calc/Impress, DLL, Python и другие рабочие компоненты сохраняются.** Две базовые темы значков остаются.
- Blender: удаляются PDB-символы отладки, внешние файлы GPU-ядер Cycles, студийное освещение интерактивного viewport и лишние переводы интерфейса. NOP использует Blender для импорта/экспорта моделей; Python, все импортёры/экспортёры, OpenColorIO и шрифты остаются. Изучены таблицы обычных и отложенных PE-импортов 247 файлов: **`cycles_kernel_oneapi_aot.dll` прямо импортируется из `blender.exe`, поэтому она сохранена**, как и все остальные DLL.
- Inkscape: убираются учебные материалы редактора, документация расширений, заголовки и статические импортные библиотеки разработчика, файлы pkg-config/CMake и ненужные переводы интерфейса. DLL, Python, сами расширения форматов, Poppler/CMap, шрифты и рабочие ресурсы сохраняются.
- calibre: убираются дополнительные языковые пакеты интерфейса Qt WebEngine, голосовые данные отдельной функции TTS, интерфейс отдельного HTTP-сервера и встроенные рецепты загрузки новостей. `ebook-convert`, `calibre-debug`, Python, Qt WebEngine/PDF, библиотеки, шрифты, переносы и фильтры сохраняются. **`locales.zip` сохранён целиком**, поскольку он содержит также ISO-данные языков и `lcdata.calibre_msgpack`.
- Файлы лицензий, уведомления и авторские права не удаляются. Полные оригинальные SDK-архивы и подготовленные движки в `runtime_deps` остаются вне установщика.

## Как проверяется конкретная Windows-сборка

1. Собирается полный EXE с полными конвертерами; штатная проверка Python/Qt/медиакомпонентов остаётся обязательной.
2. Замороженный NOP.exe через настоящие `ConversionCapabilityProbe` и `ConverterWorker` выполняет попытки **61 направления экспорта** для шести категорий внешних движков. Фикстуры содержат кириллицу и пути с пробелами. Уже неподдерживаемые направления и ошибки чтения результатов фиксируются отдельно.
3. Шесть базовых преобразований обязаны пройти ещё до сокращения: документ→PDF, CSV→XLSX, презентация→PDF, OBJ→GLB, SVG→PNG и EPUB→TXT.
4. Файлы перемещаются в журнал восстановления **вне `dist/NOP`**; переписываются только регистрации словарей LibreOffice. Оригинальные кэши не затрагиваются.
5. Тот же EXE повторяет ту же матрицу. Сверяются доступные форматы, все успешные экспорты, а для корректно проверенных результатов — текст, страницы и растровое представление PDF, пиксели изображений, текст книг и геометрия после чтения моделей через GLB. Контейнеры ZIP проверяются CRC.
6. При потере экспорта, изменении возможностей или проверенного результата восстанавливается полный соответствующий движок и запускается повторная проверка. Если проверка прервана или восстановление не устранило проблему, упаковка останавливается. Неподдерживаемый формат базового комплекта не объявляется исправным.
7. Генерируются актуальные манифесты, затем выполняются прежние функциональные проверки mpv/всех категорий/перекодирования/отмены/панелей/состояния. Созданные тестами кэши и настройки движков переносятся за пределы установочного каталога. Если поставлявшийся с SDK PYC был пересоздан Python из-за времён файлов после распаковки, восстанавливаются его проверенные исходные байты из полного кэша; исходный PYC не удаляется. Изменения прочих поставленных файлов блокируют сборку. Только после этой проверки Inno создаёт установщик.

Журналы: `build/converter-compaction/before.json`, `after.json`, при восстановлении `after-restore.json`, `summary.json` и соответствующие `.native.log`. Итоговый отчёт копируется в `release`. Полные SDK остаются в кэше для повторного запуска. После аварийного прерывания обычный сборщик заново создаёт `dist` из полных кэшей; старый журнал сохраняется для диагностики.

## Совместимость и ограничения

Минимум этой ветки прежний: Windows 10 x64 1809/17763, далее Windows 10/11 x64 — кандидаты для тестирования, **не сертифицированные здесь системы**. Ранние Windows 10 и Windows 7 этой веткой не поддерживаются. Полная приёмка установленного EXE на чистой LTSC 1809 всё ещё нужна. Фиксированная матрица проверок не доказывает корректность каждого произвольного сложного документа, материала модели, экзотического шрифта или входного формата.

Полный список панелей и функций — `PANELS_RU.csv`, `CONVERSION_MATRIX.csv`, `CODE_INVENTORY.json`. SHA-256 исходника плеера: `e03e64ab9ce60762e7c381c2f6fa3ab48b0a769cb1db4487a6c13a7f0d3f4ab2`. Торрент/RuTracker/WebView2 в исходной ветке этого BuildKit отсутствовали и этим обновлением не удалялись.
