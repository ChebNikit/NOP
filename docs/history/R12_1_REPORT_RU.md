# NOP 1.0 — отчёт BuildKit R12

**Обновление R12.1 (30 октября 2026):** исправлено преждевременное подключение `installer_versions.iss` в ранней проверке Inno. Проверочный EXE использует отдельные метки и отказывается запускать установку; итоговый `NOP_Setup.exe` по-прежнему требует реальные версии из `assemble_bundle.py`. Добавлен импорт кэшей, распакованных отдельно в соседние `NOP_R12_CACHE_*`. Для уже распакованного R12 достаточно `NOP_R12_1_FIX.bat`: положите его рядом с `build_windows.bat` и запустите. Он обновит файлы и продолжит сборку с сохранением Python, установленных пакетов и загрузок. Windows-компиляция исправления в этой среде не выполнена.

Дата: 30 октября 2026 года. Полный комплект заменяет R11 и патчи R11.2–R11.5.

**Результат: подготовлен BuildKit и все большие пакеты зависимостей. Из-за ограничения 512 МБ на файл доставка состоит из основного ZIP и трёх необязательных ZIP кэша SDK; без дополнительных ZIP основной сборщик получает SDK автоматически. Готовый `NOP_Setup.exe` в этой среде не создан. Полная сборка и установленное приложение на Windows, особенно Windows 10 Enterprise LTSC 2019 / 1809 / 17763, ещё не проверены. Главный критерий исходного задания пока не достигнут.** Это ограничение не скрывается успешными модульными тестами или проверкой архивов.

Последний предоставленный пользователем журнал показывает успешные 69 тестов R11.5, запуск FFmpeg/ffprobe и Deno, загрузку API libmpv на Windows. Затем настоящая распаковка LibreOffice через Windows Installer завершилась кодом 1603. Версия Windows в этом журнале не указана; его нельзя приписать LTSC 1809. Сам по себе 1603 не раскрывает причину; без `extract-libreoffice.log` нельзя доказать, были ли причиной длина пути, политика, права или установочные действия MSI.

## Изменён подход подготовки движков

R12 не вызывает `msiexec /a` для LibreOffice, Inkscape и calibre. Исходный официальный MSI проверяется по закреплённому SHA-256. Полный приватный 7-Zip 26.05 читает конкретный встроенный CAB как данные. Список ключей и размеры сверяются с таблицами именно этого MSI; после проверки CRC восстанавливаются настоящие имена файлов и каталоги. Регистрация продукта, изменения реестра, установочные действия MSI и системная установка офисных приложений не выполняются.

Карты `bootstrap/msi/*.json` построены из File, Component, Directory и Media реальных официальных пакетов и закреплены хешами. Системные VC merge-модули исключены: в LibreOffice они содержат x86, x64 и ARM64 и могут иметь одинаковые конечные имена. Необходимый Visual C++ устанавливается отдельно оригинальным Microsoft-установщиком с UAC. 135 шрифтов из MSI сохраняются в частной папке LibreOffice `share/fonts/truetype`, которую его Windows-код регистрирует для приложения. У 29 ключей CAB Inkscape есть точки в конце; обработка учитывает замену таких символов Windows-версией 7-Zip. Конечные имена файлов берутся из карты, а не из ключа CAB.

Все большие пакеты получены и проверены; SDK передаются в трёх отдельных архивах кэша, остальные компоненты — в основном ZIP. Новая рабочая папка `%LOCALAPPDATA%\NOPBK\R12` уменьшает длину путей. Кэши соседних комплектов импортируются; исправные загрузки повторно не скачиваются. Неполные рабочие копии восстанавливаются из полного комплекта по SHA-256. Переход на новую карту файлов меняет рецепт подготовки, поэтому старый неподходящий результат не принимается только по совпадению версии MSI.

## Панели и функции

Исходник `NOP_1.0.py` не изменялся относительно R11.5: SHA-256 `e03e64ab9ce60762e7c381c2f6fa3ab48b0a769cb1db4487a6c13a7f0d3f4ab2`; сохранены 78 классов. Полный перечень и методы — `PANELS_RU.csv`, `CODE_INVENTORY.json`, `UI_CONNECTIONS.csv`. Категории/форматы конвертации — `CONVERSION_MATRIX.csv`. В исходнике 11 категорий и 140 записей форматов; наличие пункта не является подтверждением каждого экспорта, кодека, GPU-энкодера или дополнения Blender.

Сохранены: видео/аудиоплеер и очередь; управление и профили; список треков; изменение размеров и полноэкранный режим; загрузки и их прогресс; конвертация; перекодирование; эквалайзер NOP и мост APO; цветокоррекция/LUT; настройки, RU/EN, темы и состояние; справка, аватар и QR; файловые диалоги и вспомогательные процессы. **Для каждой из этих панелей наличие кода проверено статически, фактическая работа установленного R12 на Windows — не проверено.** Все строки отдельной таблицы панелей сохранены.

Торрент-клиент, RuTracker и WebView2 в предоставленном исходнике не обнаружены; они не удалялись. Ветку с иными функциями нельзя подтвердить по этому исходнику. Интернет-загрузка и поиск на внешних сервисах требуют сети и при необходимости авторизации; локальные медиа и конвертация не должны зависеть от неё. Реальный YouTube-тест теперь отдельный: `NOP_TEST_ONLINE=1`; обязательная проверка включённых yt-dlp/EJS/Deno остаётся.

## Причины исправлений

| Ошибка/риск | Решение R12 |
|---|---|
| WinError 2 при запуске PowerShell | Абсолютные пути ко всем системным PowerShell-вызовам; глобальный PATH не используется |
| Ошибка старого `File.Replace` | Старый текстовый патчер не нужен: полный комплект уже содержит исправленные файлы |
| Неподдерживаемый BCJ2 в py7zr | Проверенный нативный 7-Zip 26.05 остаётся в комплекте |
| MSI 1639 и затем 1603 | В подготовке офисных движков удалён вызов Windows Installer; применяется извлечение данных CAB |
| Слишком длинные пути | Постоянная короткая рабочая папка и расширенные файловые пути в подготовке движков |
| Простой CAB-экстрактор теряет структуру | Закреплённая карта File/Component/Directory/Media восстанавливает длинные имена и папки |
| Совпадающие системные DLL разных архитектур | Системные merge-модули не копируются в приложение; VC устанавливается отдельно |
| Потеря шрифтов при выборе только каталога LibreOffice | 135 шрифтов из того же MSI сохраняются в частном каталоге LibreOffice |
| Ключи Inkscape заканчиваются точками | Учитывается нормализация 7-Zip под Windows, после чего восстанавливаются настоящие имена |
| HTTP 429 и неполный файл с двумя источниками | Все четыре источника и оригинальные архивы включены; метаданные при сборке не запрашиваются |
| Повторная полная загрузка после ошибки/новой распаковки | Постоянный workspace, импорт соседних кэшей, проверка и локальное восстановление по SHA-256 |
| Неполная установка Python-пакетов | Изолированный NuGet Python и повторная установка закреплённых wheels без сети |
| Будущая ошибка сценария установщика обнаруживается в конце | Компилятор включён и разворачивается в официальном portable-режиме; предварительная компиляция сценария выполняется раньше больших SDK |
| Недоступность YouTube блокирует локальный установщик | Настоящий сетевой тест вынесен в отдельный режим, с честным «не проверено» по умолчанию |
| Новый неполный результат затирает старый выпуск | Сохранена проверяемая публикация только после обязательных успешных этапов |

## Матрица совместимости и оставшиеся ограничения

`COMPATIBILITY_MATRIX_RU.csv` содержит ранние Windows 10, LTSC 2019/17763, последующие Windows 10 и Windows 11. **Ни одна строка не объявлена подтверждённой установленным R12.** Qt 6.11 допускает Windows 10 1809 и выше; это не доказывает совместимость всех Python/native-зависимостей и установленного плеера. Выпуски Windows 10 до 1809 блокируются; порт на Qt 5 или иной UI-backend не выполнен.

Для завершения исходной задачи нужен настоящий Windows-стенд, обязательно чистая Enterprise LTSC 1809/17763: построить полный EXE, установить, воспроизвести медиа, проверить все категории конвертации и пресеты, UI, отмену, повреждённые файлы, права, кириллицу, состояние и рестарт; затем обновление, переустановку и удаление. Отдельно — Windows 11 и заявляемые другие выпуски, отсутствие Edge/WebView2/Python/FFmpeg и мультимедийных системных компонентов, GPU/звук/APO. Полный список — `WINDOWS_ACCEPTANCE.csv`.

Дополнительные ограничения: каждый формат/фильтр зависит от фактических возможностей закреплённого движка; аппаратные энкодеры требуют подходящих устройств и драйверов; системный APO требует согласия и выбора устройства; корпоративная политика запуска и отказ в UAC могут остановить работу. Проверка цифровой подписи Microsoft зависит от доверенных корневых сертификатов Windows; на нестандартно урезанной системе может потребоваться восстановление штатного доверия. Ни антивирус, ни политики безопасности сборщик не отключает.
