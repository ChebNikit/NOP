# Исправление NOP BuildKit R11.3: распаковка FFmpeg BCJ2

Этот архив исправляет остановку сборки на сообщении `BCJ2 filter is not supported by py7zr`. Он предназначен для существующего BuildKit R11, в том числе после успешного применения R11.2.

1. Закройте завершившееся окно сборки. Не удаляйте `.build-python`, `runtime_deps` или `.build-tools`.
2. Распакуйте содержимое этого ZIP в папку, в которой находится ваш `build_windows.bat`. Рядом с ним должны появиться `NOP_R11_3_FIX_BCJ2.bat` и папка `nop_r11_3_patch`.
3. Запустите `NOP_R11_3_FIX_BCJ2.bat`.
4. Патч проверит хеши файлов и выполнит настоящую распаковку небольшого архива BCJ2 в путь с пробелами и кириллицей. Только после этого он обновит исходники и проверит установленный распаковщик повторно.
5. После сообщения `R11.3 fix complete` автоматически продолжится обычная сборка. Полный архив FFmpeg проверяется по прежнему SHA-256 и повторно используется из кэша, если он цел.

Новый распаковщик — официальный неизменённый `7za.exe` 26.05 x64 из 7-Zip Extra, включённый в этот архив. Системная установка 7-Zip, изменение системного PATH, административные права и дополнительные загрузки для применения патча не нужны. Сама дальнейшая сборка по-прежнему получает остальные компоненты из сети.

Изменяются `archive_tools.py`, тесты распаковки и, если это ещё не сделано, вызовы PowerShell в `build.py` и `prepare_components.py`. Распаковщик, лицензии, соответствующий исходный код и тестовый архив помещаются в `.build-tools/7zip-26.05`. Сам плеер и его панели этим исправлением не изменяются.

Уже установленный приватный Python, пакеты и скачанные компоненты сохраняются. Перед первой заменой трёх скриптов создаются копии `*.R11_before_BCJ2_fix.bak`. При ошибке применения ранее заменённые файлы восстанавливаются; сборка не запускается. Повторное применение допускается. Если исходник отличается от ожидаемого R11/R11.3, патч останавливается до изменения файлов.

Диагностика патча: `logs/patch-r11_3-*.log`. Диагностика следующего этапа: `logs/build-*.log`, `logs/last-build.json` и `.build-tools/runtime-preparation.log`.

| Работа самого патча R11.3 и 7za.exe на компьютере пользователя | не проверено | Патч выполнит локальный тест BCJ2 до изменения исходников |
| Готовый NOP_Setup.exe, установка, mpv, конвертация, панели, LTSC 1809 | не проверено | Эти этапы ещё не пройдены; совместимость не объявляется подтверждённой |

Распаковка в Linux не является проверкой работы Windows EXE. Исходный главный критерий — полностью работоспособный установленный плеер — пока не достигнут.

Исходный архив FFmpeg: `ffmpeg-9.0.2-full_build.7z`, 168971636 байт, SHA-256 `f0e46253c70dfe902bac915dfb4224f0cf1b7c6eeab9da2ccc9a5581f9a71b13`.
