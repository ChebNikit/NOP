Author images shown in NOP ("About" / "Support the author"):
avatar.jpg, donate_crypto_qr.jpg, donate_ozon_qr.jpg.
NOP also accepts .png, .jpeg and .webp with the same names; donate_boosty_qr.* is optional.
Everything in this folder is copied to <install folder>\assets by the build.
An empty folder is fine: NOP then simply shows no images.
The application icon (nop.ico) is NOT needed here: the build generates it from the icon embedded in NOP_1_3.py.
