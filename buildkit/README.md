# NOP 1.3 — сборщик установщика (NOP_Setup.exe)

Двойной щелчок по **`BUILD_NOP_SETUP.bat`** — и в папке `dist` появится `NOP_Setup.exe`.
Нужны Windows 10 (1809+) или 11 x64, интернет при первой сборке и ~25 ГБ свободного места (с движками конвертации; без них ~8 ГБ). Для движков нужен winget 1.6+ (есть в Windows 11 и современной Windows 10).
Ничего не нужно ставить заранее: сборщик сам скачивает недостающее и ничего не меняет в системе (ни Python, ни PATH, ни реестр).

## Что делает сборка

| Шаг | Что происходит |
|---|---|
| 1 | Проверка системы: Windows ≥ 1809, x64, место на диске, длинный путь, облачные папки |
| 2 | Личный Python 3.13 в `.build\python` (официальный пакет NuGet, подпись Python Software Foundation проверяется) и библиотеки из `config\requirements.lock`: **у каждого файла проверяется SHA-256**, ставятся только готовые колёса |
| 3 | Рисует оформление установщика (тёмная панель, знак N, «NOP / NikOmniPlayer») из значка самого NOP |
| 4 | Скачивает **libmpv, FFmpeg + ffprobe, deno, 7-Zip** и установщик **Equalizer APO 1.4.2** (системный эквалайзер) по ссылкам и SHA-256 из `config\components.lock.json` (при несовпадении или недоступности сборка останавливается) |
| 5 | **Движки конвертации** (LibreOffice, Inkscape, Calibre, Blender) для разделов «Документы», «Таблицы», «Презентации», «Векторная графика», «Электронные книги», «3D-модели»: `winget download` (winget сам проверяет SHA-256 по манифесту), распаковка **без установки** (MSI → папка), укладка в `converters\…`. Если winget недоступен — берётся копия, установленная на этом ПК, либо распакованная вручную в `cache\engines\<имя>` |
| 6 | PyInstaller (папка, не один файл — быстрее старт и меньше ложных срабатываний антивирусов) |
| 7 | Сборка папки программы: рядом с `NOP.exe` кладутся `ffmpeg.exe`, `ffprobe.exe`, `deno.exe`, `mpv\libmpv-2.dll`, лицензии и конвертеры |
| 8 | **Проверка собранной программы**: libmpv загружается и инициализируется, FFmpeg кодирует звук с фильтром эквалайзера и видео H.264, ffprobe читает, пакеты импортируются; **реальные конвертации**: текст→PDF (LibreOffice), SVG→PNG (Inkscape), текст→EPUB (Calibre), запуск Blender; NOP должен распознать все шесть разделов конвертации. Если что-то не работает — установщик **не создаётся** |
| 9 | Поиск или загрузка Inno Setup (подпись проверяется) |
| 10 | Inno Setup компилирует `NOP_Setup.exe` + `.sha256` |
| 11 | Пробная установка, проверка и удаление (только с `--verify-install`) |
| 12 | Отчёт `BUILD_REPORT.json` |

Если какого-то файла нет в `cache\`, он скачивается. Если интернета нет — положите нужные файлы в `cache\` под теми же именами и запустите `BUILD_NOP_SETUP.bat --offline`.

## Параметры

`BUILD_NOP_SETUP.bat --offline` · `--skip-verify` (не рекомендуется) · `--no-engines` (лёгкий установщик без документов/векторов/книг/3D) · `--clean` · `--from-step N` (продолжить с шага N, например 10: только перекомпилировать установщик) · `--verify-install` (после сборки тихо ставит, проверяет и удаляет NOP; **только на тестовом ПК**: использует тот же AppId установщика) · `python build\build_kit.py --list` показывает шаги.

Подпись кода: задайте `NOP_SIGN_CMD`, например `signtool sign /fd sha256 /a /tr http://timestamp.digicert.com /td sha256 $f` (`$f` — путь к exe). Без подписи Windows SmartScreen может предупреждать при первом запуске.

## Что делает установщик

* Тёмный мастер в оформлении первой («Классической») темы плеера: фон #0d0f14, акцент #ff426d, на русском и английском (язык по системе), Windows 10 1809+ x64, обновление поверх старой версии. В начале — приветственная страница NOP 1.3; дальше идут выбор типа установки, страница «Конвертеры файлов» (если конвертация выбрана), папка в меню «Пуск» и дополнительные задачи. Перед подтверждением — отдельный самостоятельный шаг «Состав установки»: он показывает версии встроенных библиотек и выбранные конвертеры и не занимает место страницы выбора типа.
* Установка «только для меня» (без прав администратора, по умолчанию) или «для всех» (диалог выбора).
* Ярлыки, пункт «Открыть с помощью» для всех форматов NOP (необязательно). Программой по умолчанию Windows управляет сам пользователь — это делается в настройках NOP.
* При необходимости ставит Microsoft VC++ Runtime (проверка подписи, только если его нет).
* **Equalizer APO 1.4.2** встроен в установщик и запускается им, если APO ещё нет в Windows (режим эквалайзера «Всё устройство»). Нужно подтверждение прав администратора, а в мастере APO — выбрать устройство звука; поэтому при тихой установке (`/SILENT`) APO пропускается. Уже установленный APO и его настройки не трогаются, при удалении NOP APO остаётся.
* **Конвертеры выбираются по одному.** В «Полной» и «Выборочной» установке после страницы типа идёт страница «Конвертеры файлов» с раскрывающимся разделом «Конвертация файлов» (клик по заголовку сворачивает и разворачивает список): LibreOffice — документы, таблицы, презентации; Inkscape — векторная графика; Calibre — электронные книги; Blender — 3D-модели. У каждой программы указан размер (считается по реально собранным папкам), по умолчанию отмечены все. Выбранные лежат в `converters\<имя>` рядом с NOP; тип «Компактная» их не ставит. Выбор запоминается и предлагается снова при обновлении. Тихая установка: `NOP_Setup.exe /SILENT /ENGINES=libreoffice,blender` (`all` — все, по умолчанию; `none` — ни одной). Ничего скачивать при установке не нужно. NOP ищет каждую программу отдельно, поэтому часть из них можно не ставить.
* **Папка в меню «Пуск».** Мастер показывает страницу «Выбор папки в меню Пуск» (по умолчанию `NOP`, название можно изменить) с галочкой «Не создавать папку в меню Пуск». В папке: **NOP**, **Удалить NOP**, **NOP — проверка установки** (`Check_NOP.bat`), **NOP на GitHub**. Если галочка стоит, в «Пуске» ничего не создаётся (значок на рабочем столе — отдельный пункт на странице задач). Старый одиночный ярлык предыдущих установщиков при обновлении удаляется.
* **Проверка конвертеров выполняется один раз при установке** (`NOP.exe --nop-warm-capabilities`) и сохраняется в `%APPDATA%\YamiFM\capabilities.json`. При обычном запуске NOP читает кэш за миллисекунды и **не запускает** FFmpeg, LibreOffice и другие программы. Проверка повторяется сама, только если эти программы изменились (путь, размер, дата) или вышла другая версия NOP.
* После установки запускается самопроверка (`--nop-selftest`); результат показывается на последней странице. Скрипт `Check_NOP.bat` в папке программы повторяет её в любой момент.
* Обновление поверх старой версии: папки `_internal`, `mpv` и `licenses` перед копированием удаляются целиком, чтобы файлы прежней версии не подхватывались новой. `converters\`, настройки в `%APPDATA%\YamiFM` и всё вне папки программы не трогаются.
* Удаление: файлы и ключи реестра; настройки в `%APPDATA%\YamiFM` удаляются только по вашему согласию.

## Что в приложении изменено для 1.3

Исходник — `source\NOP_1_3.py`, версия 1.3 (служебные части для установщика сохранены: режимы `--nop-warm-capabilities` и `--nop-selftest`, кэш проверки конвертеров). Главное в 1.3: случайный порядок кругами и повтор любого трека, выбор формата для «Только аудио», удаление в корзину, единый стиль окон подтверждения и ввода, выделение в списках в цвет темы, плюс исправления в «Свойствах» mp3, полноэкранном режиме и проводнике.

Полный список, включая изменения установщика, — в `docs\RELEASE_NOTES_1.3.md`. Заметки к 1.2 остались в `docs\RELEASE_NOTES_1.2.md`.

## Что проверено, а что нет

Подробно — в `docs\VERIFICATION.md`. Коротко: автор собрал установщик на Windows, установил его и подтвердил, что программа запускается и работает. На Linux проверены логика кэша, самопроверка, заморозка PyInstaller, модульные тесты сборщика, синтаксис PowerShell и закреплённые хэши загрузок. Отдельно не проверялись: Windows 10 LTSC 1809, обновление поверх старой версии (в том числе чистка `_internal`), установка «для всех», удаление, каждый движок конвертации по отдельности, а также выбор конвертеров, страница папки «Пуск» и `/ENGINES=` (проверены только тестами и по исходникам Inno Setup); `--verify-install` на тестовой машине закрывает часть этих пунктов.

## Размер и время

С движками конвертации установщик получается порядка 1,5–2,5 ГБ, а сжатие занимает десятки минут. Если Inno Setup откажется из-за размера, соберите лёгкую версию `--no-engines` и сообщите точный текст ошибки. Лицензии: LibreOffice — MPL-2.0, Inkscape и Calibre — GPL, Blender — GPL.

## Если что-то пошло не так

* **Не подготовился движок конвертации** — `winget upgrade --id Microsoft.AppInstaller`, либо установите программу на этом ПК (копия берётся из Program Files), либо распакуйте её в `cache\engines\<libreoffice|inkscape|calibre|blender>`, либо `--no-engines`.
* **«Cannot reach … / не удаётся скачать»** — прокси/антивирус/DNS. Скачайте файл вручную в `cache\` или используйте `--offline`.
* **Не скачался Equalizer APO** (SourceForge недоступен или хэш не совпал) — скачайте `EqualizerAPO-x64-1.4.2.exe` вручную со страницы из `config\components.lock.json` (`installers.equalizer_apo.source`), положите в `cache\` и повторите; хэш файла должен совпасть с закреплённым.
* **«SHA-256 … does not match»** — файл подменён или повреждён; сборщик его не использует. Удалите из `cache\` и повторите.
* **Antivirus удаляет файлы в `.build`** — добавьте папку комплекта в исключения.
* **Ошибки длинных путей** — перенесите комплект ближе к корню диска (`C:\NOP_Kit`).
* **Не скачался Inno Setup (ошибка 404 и т.п.)** — сборщик загружает официальный Inno Setup 6 с GitHub Releases, проверяет цифровую подпись и использует уже установленный Inno Setup 6, если его версия определяется только по папке. Встроенная тёмная тема включается на версиях 6.6+; для более ранней совместимой 6.x действует запасное оформление. Если загрузка недоступна, установите Inno Setup с https://jrsoftware.org/isdl.php и продолжите сборку командой `BUILD_NOP_SETUP.bat --from-step 9` (шаги 1–8 повторно не выполняются).
* **ISCC не нашёл Russian.isl / слишком старый Inno** — удалите `.build\innosetup` и запустите снова; минимальная версия для сборки — Inno Setup 6.5+, для полной встроенной тёмной темы рекомендуется 6.6+.
* Журнал каждого шага печатается в окно; сохраните его при обращении за помощью.

## Свой (изменённый) файл NOP

Можно собирать установщик из своей версии программы. Берите за основу `source\NOP_1_3.py` (в нём есть служебные части для установщика: режимы `--nop-selftest` и `--nop-warm-capabilities`, встроенный значок, `MEDIA_EXTS`, защита `_guard_optional_zstd`). Два способа:

* заменить файл `source\NOP_1_3.py` своим (имя сохранить) и запустить `BUILD_NOP_SETUP.bat --from-step 5` (снова собираются конвертеры из `cache`, программа и установщик);
* не трогать комплект и указать путь: `BUILD_NOP_SETUP.bat --from-step 5 --source "C:\путь\к\моему_NOP.py"`.

Версия берётся из строки `APP_VERSION = "x.y"` вашего файла. Если нужных частей нет, сборщик сразу остановится и перечислит, чего не хватает. Новые библиотеки, которых нет в `config\requirements.lock`, нужно добавить в `requirements.in` и пересоздать lock-файл.

## Обновление компонентов

Измените `url`, `version`, `sha256` в `config\components.lock.json` (хэш: `certutil -hashfile файл SHA256`). Python-пакеты: `config\requirements.in` → пересоберите `requirements.lock` (`pip download` + `--require-hashes`).

## Лицензии

FFmpeg распространяется по GPL, libmpv — по LGPL; исходный код доступен по ссылкам из `licenses\THIRD_PARTY_NOTICES.txt` (кладётся в установленную программу). PyQt6 — GPL-3.0/коммерческая, PyMuPDF — AGPL-3.0/коммерческая: учтите это при публикации.

## English summary

Double-click `BUILD_NOP_SETUP.bat` (Windows 10 1809+/11 x64, internet on first run). It provisions a private Python 3.13, installs hash-locked wheels, downloads libmpv/FFmpeg/ffprobe/deno pinned by SHA-256, freezes NOP with PyInstaller, **self-tests the frozen app (mpv init, FFmpeg encode + equalizer filter, ffprobe)**, and compiles `dist\NOP_Setup.exe` with Inno Setup (dark wizard, RU/EN; each converter can be ticked separately, optional Start Menu folder with an uninstall shortcut, clean update that replaces the program's library folders). The installer runs the converter capability check **once** and NOP caches it, so normal launches start no external tools. Not verified here: the Windows build itself (see `docs\VERIFICATION.md`).
