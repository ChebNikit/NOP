# NOP 1.0 — BuildKit R12.2 Compact

Комплект уменьшает установочный пакет за счёт отбора файлов LibreOffice, Blender, Inkscape и calibre. Исходный плеер, категории конвертации, FFmpeg/ffprobe/mpv, аватар и QR сохранены. Исправление Inno из R12.1 включено.

## Для уже распакованного R12 или R12.1

1. Сохраните `NOP_R12_2_COMPACT.bat` **рядом с `build_windows.bat`** в `NOP_BuildKit_Win10_11_R12`.
2. Запустите `NOP_R12_2_COMPACT.bat`. Он проверит исходные хеши, сохранит резервные копии обновляемого кода и продолжит сборку.
3. Python, установленные пакеты, компилятор и все скачанные архивы сохраняются. Рабочая папка остаётся `%LOCALAPPDATA%\NOPBK\R12`; папки `NOP_R12_CACHE_*` могут лежать рядом, как в R12.1.

## С чистого компьютера

1. Распакуйте обновлённый `NOP_BuildKit_R12.zip` целиком. Внутри находится прежняя папка `NOP_BuildKit_Win10_11_R12`, а в `BUILDKIT_VERSION.txt` указано R12.2.
2. Необязательно распакуйте три прежних `NOP_R12_CACHE_*.zip` в ту же папку назначения. Без них сборщик ищет прежний кэш или получает официальные архивы по закреплённым хешам.
3. Запустите `build_windows.bat`. Глобальные Python, FFmpeg, mpv, Inno Setup и настройка PATH не требуются. При необходимости установки VC Windows запросит согласие с UAC.
4. Дождитесь `CREATED`. Итог: `release\NOP_Setup.exe`; рядом появится `CONVERTER_COMPACTION_REPORT.json` с фактическим размером EXE и принятыми сокращениями.

Для полных исходных кэшей и сборки требуется не менее 18 ГиБ свободного места, предпочтительно 25 ГиБ. Сокращается состав будущего установщика; оригинальные архивы первого скачивания и полные движки для проверки остаются в кэше. Прежние архивы кэшей подходят без изменений.

Сборщик проверяет реальные преобразования до и после сокращения. При регрессии возвращается полный соответствующий движок. Это может уменьшить экономию, зато сокращённый вариант с обнаруженной ошибкой не попадёт в установщик. Журналы — `build\converter-compaction`, обычные логи — `logs`.

**Проверено здесь:** на Linux выполнены настоящие распаковка, сокращение и побайтное восстановление Windows-пакетов; по составу убирается около 1,28 ГиБ несжатых данных. **Не проверено здесь:** полная Windows-сборка, реальные Windows-конвертации, установка и обязательная LTSC 1809. В архиве нет готового `NOP_Setup.exe`. Полный отчёт — `docs/REPORT_RU.md`.

Минимум этой Qt 6 ветки — Windows 10 x64 1809/17763; Windows 11 x64 также требует приёмки. Совместимость установленного приложения на этих системах не заявляется без реального теста. Изменения интерфейса плеера в это обновление не входят.

Другой диск для рабочей папки, необязательно из CMD:

```bat
set "NOP_BUILD_WORKSPACE=D:\NOPBK\R12"
build_windows.bat
```
